# Sion Bible 페이지 완성도 감사

검토 기준 브랜치: `agent/page-completion-wave-6`

## 감사 원칙

- 파일 존재 여부만으로 완료 처리하지 않는다.
- 사용자 진입 경로, 저장·복원, 오류 상태, 모바일 안전 영역, 접근 가능한 버튼을 함께 확인한다.
- 외부 서비스 결제·권한 문제와 애플리케이션 코드 결함을 분리한다.
- 대규모 개선은 한 번에 병합하지 않고 검증 가능한 웨이브 단위로 진행한다.

## Wave 1 — 본문 탐색 상태 정합성

- 성경책과 장을 `(book, chapter)` 단일 콜백으로 갱신한다.
- 새 책 선택 직후 이전 성경책이 마지막 읽기 위치로 저장될 수 있는 상태 스냅샷 오류를 제거했다.
- `scripts/audit-bible-navigation.mjs`로 오래된 분리 콜백과 이전 상태 참조를 차단한다.

## Wave 2 — 통독 하위 화면

- `/reading-room/course-detail`: 기간, 분량, 보상, 진행률, 오늘 본문, 시작·이어 읽기·미션 진입.
- `/reading-room/mission`: 장별 체크리스트, 본문 읽기, 완료 처리, 마지막 날 완주 전환.
- `/reading-room/course-complete`: 완주 결과, 포인트·연속 일수·분량·배지, 다음 코스와 복귀.
- 선택 코스를 저장해 새로고침 뒤에도 복원한다.
- `scripts/audit-reading-room-routes.mjs`로 세 경로와 헤더·하단 탐색을 검사한다.

## Wave 3 — 암송 알림 예약 엔진

- 지정 시간 모드의 다음 알림을 매일 계산한다.
- 하루 1·3·5회 모드를 활동 시간에 균등 배분하고 자정을 넘는 구간도 처리한다.
- 자동 모드에서 새 암송 구절에 복습 간격 일정을 생성한다.
- 앱 시작·포커스·화면 복귀·저장소 변경 시 예약을 복구한다.
- 서비스 워커 알림, 브라우저 대체 알림, 클릭 후 암송 탭 복귀를 연결했다.
- 테스트 알림, 권한 거부 안내, 다음 알림 미리보기를 제공한다.
- `scripts/audit-memory-reminders.mjs`로 세 모드와 PWA 연결을 검사한다.

현재 범위는 로컬 PWA 예약이다. 앱이 완전히 종료된 동안에도 운영체제가 확정 발송하려면 VAPID 키, Push 구독 DB와 서버 Cron이 필요하다.

## Wave 4 — 통독 묵상과 포인트 상점

### 통독 미션 묵상

- 무반응이던 `묵상하기`를 날짜·본문 기준 기록창으로 연결했다.
- 빈 내용 방지, 저장·불러오기·수정, 저장 상태 표시, ESC·배경·닫기와 모바일 안전 영역을 처리한다.

### 포인트 상점

- 획득 포인트에서 누적 사용 포인트를 차감해 잔액을 계산한다.
- 부족 포인트 안내, 인벤토리 저장, 재구매 방지, 구매 완료 표시와 차감 내역을 구현했다.
- DOM 변경 감시 중 내역이 반복 재생성되지 않도록 상태 서명을 사용한다.
- `scripts/audit-reading-room-actions.mjs`로 묵상과 구매 계약을 검사한다.

## Wave 5 — 검증된 통합 백업·복원

- `gb_*`, `sion_*` 등 앱 관리 데이터만 JSON으로 내보낸다.
- 저장 말씀·묵상, 암송·복습 일정, 통독 진행·묵상, 포인트, 테마·글자 크기·마지막 읽기 위치를 포함한다.
- 토큰, 비밀번호, API 키, 인증·자격 증명으로 보이는 키는 제외한다.
- 형식·버전·내보낸 시각·출처·시간대와 정렬 데이터의 FNV-1a 체크섬을 기록한다.
- 5MB 제한, JSON 구조, 식별자, 버전, 허용 키, 문자열 값과 체크섬을 복원 전에 검사한다.
- 복원 대상 요약을 보여주고 같은 키를 병합 복원한다.
- 복원 직전 세션 롤백 사본을 만들고 `마지막 복원 되돌리기`를 제공한다.
- `scripts/audit-data-backup.mjs`로 민감정보 제외, 다운로드, 검증과 롤백을 검사한다.

## Wave 6 — 무반응 버튼 전수 감사

### TSX 대화형 요소 감사

- TypeScript AST로 `src/**/*.tsx`의 모든 `<button>`을 스캔한다.
- 직접 이벤트 핸들러, 제출·초기화 폼 동작, 비활성 상태, 스프레드 속성 또는 검증된 이벤트 위임 중 어느 것도 없는 버튼은 빌드를 실패시킨다.
- 단순 예외 목록이 아니라 실제 위임 모듈의 탐지 조건과 최종 동작까지 함께 검사한다.

전수 검사에서 직접 핸들러가 없던 버튼은 세 개였다.

1. 통독 미션 `묵상하기`: `readingRoomEnhancements.ts`의 묵상 모달·저장 동작까지 검증.
2. 포인트 상품: 상품 식별·잔액 검증·`saveRewardState` 저장 동작까지 검증.
3. 통독 상단 도움말: 실제 무반응 버튼으로 확인되어 새 안내 모달을 구현.

### 통독 도움말

- 통독 미션, 코스 상세, 일반 통독방 경로에 맞는 안내 내용을 제공한다.
- 읽기·체크·묵상·완료·포인트 흐름을 순서대로 설명한다.
- 접근성 대화상자, ESC·배경·닫기·확인 버튼과 모바일 안전 영역을 처리한다.
- `scripts/audit-interactive-buttons.mjs`가 세 위임 계약을 확인한 뒤 전체 TSX에서 남은 무계약 버튼이 없음을 보장한다.

## 검증 결과

Vercel Preview에서 다음 항목이 모두 통과했다.

- 성경 66권·31,040절 구조 감사
- 본문 탐색 상태 감사
- 통독 하위 경로 감사
- 암송 알림 감사
- 통독 묵상·포인트 감사
- 백업·복원 감사
- 전체 TSX 버튼 계약 감사
- TypeScript 검사
- Vite 프로덕션 빌드

남은 성능 경고:

- 메인 JavaScript 청크 약 634KB
- `app-book-background` 이미지 약 1.4MB
- 일부 동적 import가 정적 import와 중복되어 청크 분리에 기여하지 못함

## 현재 코드 밖의 차단 요소

1. GitHub Actions는 계정 결제 또는 Actions 지출 한도 문제로 작업 시작 전에 중단된다.
2. Vercel에 이름이 유사한 프로젝트가 둘 있어 운영 프로젝트 정리가 필요하지만 삭제는 승인 없이 수행하지 않는다.
3. 오래된 대형 Draft PR은 현재 `main`과 겹치는 변경이 많아 기능 단위로만 재검토한다.
4. 확정 백그라운드 Web Push는 구독 DB, VAPID 키와 서버 Cron이 필요하다.
5. iOS·Android 실기기의 설치, 권한과 완전 종료 상태는 실제 기기 검증이 필요하다.

| 단계 | 사용 도구 | 역할 |
| --- | --- | --- |
| 저장소 감사·수정·PR | GitHub | 파일 구조, 브랜치, 커밋, 리뷰, PR과 병합 |
| React 상태 교차검증 | Context7 | 최신 React 상태 스냅샷·배치 동작 검증 |

| 오류 구조화 | Error Log Parser | 런타임·배포 오류가 발생할 때 선택 사용 |
| UI 원본 개선 | Figma·Adobe·Canva | 기능 결함 정리 후 디자인 웨이브에서 사용 |
| 계정 동기화·Push 저장 | Supabase·Neon·Convex | 서버 데이터가 필요한 웨이브에서 사용 |
