# Sion Bible 페이지 완성도 감사

검토 기준 브랜치: `agent/page-completion-wave-5`

## 감사 원칙

- 파일 존재 여부만으로 완료 처리하지 않는다.
- 사용자 진입 경로, 저장·복원, 오류 상태, 모바일 안전 영역, 접근 가능한 버튼을 함께 확인한다.
- 외부 서비스 결제·권한 문제와 애플리케이션 코드 결함을 분리한다.
- 대규모 개선은 한 번에 병합하지 않고 검증 가능한 웨이브 단위로 진행한다.

## Wave 1에서 해결한 결함

### 성경책과 장 선택의 원자적 갱신

기존 구현은 성경책 상태를 갱신한 직후 별도의 장 선택 콜백에서 이전 렌더의 성경책 상태를 읽을 수 있었다. 그 결과 화면 본문은 새 책으로 바뀌더라도 외부에 저장되는 마지막 읽기 위치가 이전 성경책으로 기록될 가능성이 있었다.

수정 내용:

- `BibleBookChapterSelector`가 `(book, chapter)`를 하나의 `onSelectReference` 콜백으로 전달한다.
- `BibleVersePicker`가 전달받은 동일한 책·장으로 내부 상태와 외부 탐색 상태를 함께 갱신한다.
- `scripts/audit-bible-navigation.mjs`를 추가해 이전의 분리 콜백과 오래된 상태 참조가 다시 들어오면 빌드가 실패하도록 했다.

## Wave 2에서 완성한 화면

### 통독 코스 상세

- 선택한 코스의 기간, 하루 분량, 보상, 진행률, 오늘 본문을 표시한다.
- 코스 시작, 이어 읽기, 오늘 미션으로 연결한다.
- 선택한 코스 ID를 저장해 새로고침 뒤에도 동일한 상세 화면을 복원한다.

### 오늘의 통독 미션

- 오늘 읽을 장을 체크리스트로 펼쳐 표시한다.
- 본문 읽기와 완료 처리를 연결한다.
- 마지막 날 완료 시 통독 완료 화면으로 이동한다.

### 통독 완료

- 완주 코스, 읽은 분량, 연속 일수, 포인트와 배지를 요약한다.
- 다음 추천 코스 시작과 나의 코스 복귀를 연결한다.

### 탐색 정리

- 상세·완료 화면에서는 하단 탭을 숨겨 중복 탐색을 방지한다.
- 하위 화면은 자체 뒤로가기·공유 헤더를 사용한다.
- `scripts/audit-reading-room-routes.mjs`로 세 경로와 화면 렌더링이 다시 제거되지 않도록 검사한다.

## Wave 3에서 완성한 기능

### 암송 알림 예약 엔진

기존 화면은 설정값을 로컬 저장소에 기록했지만 지정 시간과 하루 횟수 모드를 실제 타이머에 연결하지 않았다. 자동 복습도 새 암송 구절 추가 흐름과 연결되지 않았고 서비스 워커 알림 대체 경로가 TODO로 남아 있었다.

수정 내용:

- 지정 시간 모드의 다음 알림을 매일 계산하고 예약한다.
- 하루 1·3·5회 모드의 시간을 시작·종료 구간에 균등 배분한다.
- 종료 시간이 시작 시간보다 이르면 자정을 넘는 구간으로 계산한다.
- 자동 모드에서 새 암송 구절 추가 시 복습 간격 일정을 생성한다.
- 앱 시작, 포커스 복귀, 화면 재활성화, 다른 탭의 설정 변경 시 예약을 다시 계산한다.
- 서비스 워커 `showNotification`과 페이지 알림 대체 경로를 연결한다.
- 알림 클릭 시 기존 창을 활성화하거나 앱을 열고 암송 탭으로 이동한다.
- 설정 화면에 다음 알림, 배분 시간, 테스트 알림, 권한 거부 안내를 추가한다.
- 암송 구절 삭제 시 해당 자동 복습 일정도 함께 제거한다.
- `scripts/audit-memory-reminders.mjs`로 세 모드, 서비스 워커, 시작 초기화, 알림 클릭 복귀를 검사한다.

### 브라우저 범위와 서버 푸시의 구분

현재 완성 범위는 앱이 열려 있거나 브라우저가 앱을 다시 활성화했을 때 예약을 복구하는 로컬 PWA 알림이다. 앱이 완전히 종료된 동안에도 운영체제가 확정적으로 발송하려면 Push 구독 저장소와 서버 스케줄러가 필요한 Web Push 인프라를 별도 웨이브로 구축해야 한다.

## Wave 4에서 완성한 기능

### 통독 미션 묵상 기록

기존 `묵상하기` 버튼은 시각 요소만 있고 클릭 동작이 없었다.

수정 내용:

- 오늘의 통독 본문과 날짜를 기준으로 묵상 기록창을 연다.
- 마음에 남은 말씀·깨달음·기도 제목을 로컬 저장한다.
- 같은 날 같은 본문을 다시 열면 기존 기록을 불러와 수정할 수 있다.
- 저장 완료 상태를 버튼에 표시한다.
- 빈 내용 저장 방지, ESC·배경·닫기 버튼, 모바일 안전 영역을 처리한다.

### 포인트 상점

기존 상점 상품은 버튼 모양만 있고 구매·차감·보유 내역 처리가 없었다.

수정 내용:

- 현재 획득 포인트에서 누적 사용 포인트를 차감해 실제 잔액을 표시한다.
- 잔액 부족 시 부족 포인트를 안내한다.
- 상품을 한 번 구매하면 인벤토리에 기록하고 재구매를 막는다.
- 구매한 상품과 사용 포인트를 로컬 저장한다.
- 포인트 내역 화면에 구매 차감 기록을 표시한다.
- DOM 변경 감시 중 구매 내역이 반복 재생성되지 않도록 상태 서명을 비교한다.
- `scripts/audit-reading-room-actions.mjs`로 묵상 저장·수정, 잔액 검증, 구매 저장, 재구매 차단, 내역 안정성을 검사한다.

## Wave 5에서 완성한 기능

### 통합 데이터 백업

설정 화면에는 사용자 데이터를 외부 파일로 보관하거나 다른 기기에서 복원하는 기능이 없었다.

수정 내용:

- `gb_*`, `sion_*`, 저장 말씀 정렬 설정 등 시온바이블 관리 데이터만 JSON 파일로 내보낸다.
- 저장 말씀, 묵상 기록, 암송 구절·복습 일정, 통독 진행, 통독 묵상, 포인트 구매, 테마·글자 크기·마지막 읽기 위치를 한 파일에 포함한다.
- 토큰, 비밀번호, API 키, 인증·자격 증명으로 보이는 키는 백업 대상에서 제외한다.
- 파일 형식과 버전을 명시하고 정렬된 데이터에 FNV-1a 체크섬을 기록한다.
- 파일 이름에 백업 날짜를 포함한다.

### 검증된 복원과 롤백

- 5MB를 초과하는 파일을 거부한다.
- JSON 구조, 백업 식별자, 버전, 허용 키, 문자열 값, 체크섬을 복원 전에 검사한다.
- 복원할 영역과 항목 수를 사용자에게 먼저 보여준다.
- 기존 데이터와 같은 키만 백업 값으로 교체하는 병합 복원을 수행한다.
- 복원 직전 현재 상태를 세션 롤백 사본으로 저장한다.
- 같은 브라우저 세션에서 `마지막 복원 되돌리기`로 복원 이전 상태를 되살릴 수 있다.
- `scripts/audit-data-backup.mjs`로 민감정보 제외, 체크섬, 크기 제한, 내보내기, 복원, 롤백, 설정 화면 연결을 검사한다.

## 현재 코드 밖의 차단 요소

1. GitHub Actions 작업은 계정 결제 또는 Actions 지출 한도 문제로 실행 전에 중단된다. 코드 빌드 실패와 별개다.
2. Vercel에 이름이 유사한 프로젝트가 둘 있어 운영 프로젝트 정리가 필요하지만, 삭제는 복구가 어려우므로 별도 승인 없이 수행하지 않는다.
3. 오래된 대형 Draft PR은 현재 `main`과 겹치는 변경이 많아 일괄 병합하지 않고 기능별로 재검토한다.
4. 백그라운드 Web Push는 구독 DB, VAPID 키, 서버 Cron 구성이 필요하다.

## 플러그인 오케스트레이션

| 단계 | 사용 도구 | 역할 |
| --- | --- | --- |
| 저장소 감사·수정·PR | GitHub | 파일 구조, 리뷰 지적, 브랜치, 커밋, PR, 병합 |
| React 상태 검증 | Context7 | 최신 React 문서 기준으로 상태 스냅샷·배치 동작 교차검증 |
| 빌드·미리보기·운영 배포 | Vercel | GitHub Actions가 막힌 동안 독립적인 빌드 검증과 배포 상태 확인 |
| 실패 로그 구조화 | Error Log Parser | Vercel 또는 런타임 오류가 발생할 때만 사용 |
| UI 원본 개선 | Figma·Adobe·Canva | 기능 결함이 정리된 후 디자인 웨이브에서 선택 사용 |
| 데이터·동기화 | Supabase·Neon·Convex | 계정 동기화와 Web Push 구독 저장이 필요할 때 사용 |
| 영상·콘텐츠 | Remotion·HyperFrames·HeyGen 등 | 앱 핵심 페이지 완성과 별개인 콘텐츠 제작 웨이브에서 사용 |

사용 목적이 없는 플러그인을 동시에 호출하지 않는다. 각 웨이브에서 결과를 검증할 수 있는 도구만 선택한다.
